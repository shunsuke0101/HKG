# HKG ⇄ 名古屋 カーゴ便 Discord 通知

香港国際空港（HKG）の貨物便 API から、名古屋（NGO）発着の便を今日〜明後日の 3 日分抽出して
Discord へ通知します。表示は Changi（SIN）通知と同一のフォーマットです（2026/11/11 完全準拠）。

## セットアップ
```bat
pip install requests
copy .env.example .env     （DISCORD_WEBHOOK_URL を記入。Webhook URL はコードに書かない）
python hkg_nagoya_flights.py --dry-run
python hkg_nagoya_flights.py
```

## 表示
```
HKG ⇄ NGO カーゴ便  |  出発 2 件 / 到着 1 件  ・ 変化 1 件
対象期間: 今日 11/11 (水) 〜 明後日 11/13 (金)

▌出発便  HKG → NGO  (2 件)                 ← 青
▌ 🔔 🛫 LD 216 ｜ 今日 11/11 (水)
▌ HKG → NGO
▌ `🛫 HKG 11/11(水) 03:50 HKT`
▌ `🛬 NGO 11/11(水) 09:07 JST (推定)`
▌ ✅ 出発済み 04:27（予定 03:50、+37分）
▌ 🔔 前回: 定刻
▌
▌ 🛫 3S 734 ｜ 明日 11/12 (木)
▌ HKG → NGO → ANC
▌ `🛫 HKG 11/12(木) 05:10 HKT`
▌ `🛬 NGO 11/12(木) 09:50 JST (推定)`
▌ 🟢 定刻どおり
▌
▌到着便  NGO → HKG  (1 件)                 ← 緑
▌ 🛬 LD 217 ｜ 明日 11/12 (木)
▌ NGO → HKG
▌ `🛫 NGO 11/11(水) 22:05 JST (推定)`
▌ `🛬 HKG 11/12(木) 01:15 HKT`
▌ 🟢 定刻どおり
```
1 便 = 1 枠を縦に並べます（便と便の間は 1 行空き）。
各枠: 見出し = 便名と日付（🔔 = 前回から変化 / 🆕 = 新規）、1 行目 = 経路、2〜3 行目 = 出発/到着の日付・時刻（各空港の現地日時、NGO は日本時間）、4 行目以降 = 状態。

状態の表記:
| 表示 | 意味 |
|---|---|
| 🟢 定刻どおり | 予定どおり（実績・変更なし） |
| ✅ 出発済み 04:37（予定 04:35、+2分） | 実際に出発/到着した時刻と、予定との差（分） |
| 🟡 時刻変更 → 23:10（予定 22:00、+70分） | 変更後の予定時刻と、元の予定との差 |
| 🟠 遅延 / 🔴 欠航 | そのまま |
| 🔵 その他 | サイトの状態文をそのまま表示 |
| 🔔 前回: 定刻 | 前回通知からの変化（前回の状態・予定時刻） |
| 🆕 新しく追加された便 | 前回通知には無かった便 |

- HKG は香港時間（HKT）、NGO は日本時間（JST）。日付は各空港の現地日付
- `推定` =（HKG→NGO 220 分 / NGO→HKG 250 分 ＋ 時差 1h。`.env` で変更可）
- **前回通知からの変化**: 見出し 🔔 = 実績・予定・状態が変わった便（状態欄に `🔔 前回: …`）、🆕 = 新しく現れた便
  - 前回状態は `notified_state.json`（送信成功時のみ更新）
  - `--only-new`: 変化が 0 件なら送信しない（1 時間ごとの定期実行向け）
  - `--reset-state`: 全件を新規扱いにする
- 色は `.env` の `DISCORD_COLOR_DEP` / `DISCORD_COLOR_ARR` で変更可

旧版は `hkg_nagoya_flights.py.bak_20261108`（Webhook URL が直書きされているので、不要なら削除してください）。
